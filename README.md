# 🎮 Ultra Tower Defense

A work-in-progress tower defense game built for the web.

## 🏰 About the Game

**Ultra Tower Defense** is a tower defense game where you place units, upgrade your team, survive enemy waves, and build stronger combinations as the battle gets harder.

The goal of this project is to create a polished tower defense game with real 3D-style units, special abilities, powerful upgrades, unique enemies, and lots of progression.

## ✨ Game Systems

The project is being built around systems such as:

- 🧍 Units with different stats, roles, and abilities
- ⭐ Special, Hero, and Collab units
- 🔥 Fire and explosive damage
- 🤖 Special units such as **mech.02**
- ⬆️ Unit upgrades
- ⚡ Auto Upgrade
- 🌟 Auto Awaken
- 👾 Enemy waves and stronger enemy types
- ⏭️ Auto Skip
- ❤️ Base health
- 🔎 Unit search and unit categories
- 🧩 Collab Fusion for maxed Collab units
- 🛒 Merchant system
- 🎟️ Unit Pass progression system
- 📈 Player progression up to level **3000**

## 🧩 Collab Fusion

Collab Fusion is designed to activate when all three required Collab units are fully maxed out, allowing them to unlock a stronger fusion.

## 🕹️ How to Run the Game

The current build is contained in `index.html`.

1. Download or clone this repository.
2. Open `index.html` in a modern web browser.
3. The game should load directly in the browser.

No installation is required for the current web build.

## 🚧 Development Status

This game is still under development. Current priorities include:

- Fixing bugs and broken buttons
- Improving performance and reducing lag
- Improving unit and enemy models
- Improving abilities and upgrade systems
- Making menus easier to use
- Fixing unit search and category navigation
- Improving wave handling and Auto Skip
- Making sure game systems work correctly together

## 🐛 Bug Fixing Rules

When working on this project:

- Fix the root cause of bugs instead of hiding errors.
- Do not remove working features just because they are complicated.
- Keep the game playable after changes.
- Check for broken event listeners, bad file paths, undefined variables, duplicate UI, spawning problems, and performance issues.
- Keep actual game units/models instead of replacing them with simple flat icons.
